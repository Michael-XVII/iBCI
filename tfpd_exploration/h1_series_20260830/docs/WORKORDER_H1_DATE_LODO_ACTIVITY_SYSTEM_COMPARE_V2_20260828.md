# H1 H-S/H-C Activity Comparison Interpretation V2

This is an interpretation-only successor to the immutable V1 2x2 score matrix. It changes no prediction, target, R2 value, checkpoint, or model state.

The V1 descriptive label incorrectly used the final growing H-C minus H-S score as evidence of a carrier-by-activity interaction. The correct interaction is the difference in differences:

`(H-C growing - H-C static) - (H-S growing - H-S static)`.

V2 descriptor-validates the exact V1 body and sidecar, verifies the same-target digest across all four cells for each date, recomputes the activity effects and interaction, and reports exact five-date bootstrap intervals. Final system level and interaction are reported separately. Neither receipt is a formal target-selected deployment claim.
